# Voice Finance Glass

Особисті фінанси з інтерфейсом **Liquid Glass** для iPhone Safari та Android. Це справжня WebGL-рефракція (не `backdrop-filter`) над живим DOM: док, панель «Додатково», випадайки й великі вікна заломлюють сторінку під собою.

Логіка (облік, борги, парсер вводу, навігація) береться з модулів Voice Finance у папці `logic/`. Інтерфейс написаний заново, у `src/`.

## Відкрити як сайт (GitHub Pages)

1. Створіть **публічний** репозиторій і завантажте в нього вміст цієї папки.
2. Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, папка `/docs` → Save.
3. Через хвилину сайт відкриється за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.
4. На iPhone: відкрийте адресу в Safari → Поділитися → «На початковий екран».

Безкоштовні Pages працюють лише з публічних репозиторіїв. У репозиторії лише код, жодних ваших даних.

## Приватність

- **Усі дані лишаються на телефоні.** Операції, борги, рахунки й налаштування зберігаються в `localStorage` браузера під ключем `voice-finance-glass-v1`. На GitHub вони не потрапляють, і сервера в застосунку немає.
- GitHub Pages віддає лише статичні файли. Як і будь-який хостинг, він бачить звичайні запити до сайту (IP, час), але не вміст застосунку.
- Зовнішні запити: бібліотека `html2canvas` з `cdnjs.cloudflare.com` і курси для бігучої строки: валюти з `api.frankfurter.dev` (ЄЦБ), крипто з `api.kraken.com`. Це безкоштовні публічні API без ключів. У запитах лише назви пар, ваших даних там немає. Вибір пар зберігається на пристрої, останні курси кешуються в `localStorage`. `html2canvas` можна покласти в репозиторій, щоб працювало без CDN.
- Сховище браузера прив'язане до домену. Safari-вкладка та іконка на початковому екрані мають **окремі** сховища. Дані в одному не з'являться в іншому, а на іншому домені вони теж не з'являться.
- Якщо старий Voice Finance хоститься на тому ж `<логін>.github.io`, це інший ключ сховища, тож дані двох застосунків не змішуються й не перезаписуються. Імпорту старих даних поки немає.
- Очищення даних сайту в Safari стирає й ці дані. Кнопка «Експорт JSON» у налаштуваннях зберігає копію (працює у звичайному браузері, а не в артефакті Claude).

## Розробка

```bash
npm install          # esbuild
npm run build        # збирає docs/index.html із src/ та logic/
npm test             # 87 тестів логіки
npm run serve        # локальний сервер на :8080
node tools/smoke.cjs # димова перевірка в headless Chromium (потрібен playwright)
```

`docs/index.html` комітиться зібраним. Після змін у `src/` чи `logic/` запустіть `npm run build`. CI (`.github/workflows/test.yml`) запускає тести й перевіряє, що збірка проходить.

## Структура

| Шлях | Що це |
|---|---|
| `src/style.css`, `src/body.html` | стилі та каркас сторінки |
| `src/core.js` | ініціалізація логіки, рендер сторінок і блоків |
| `src/engine.js` | WebGL-шейдер скла, знімки DOM у текстури, док, крапля-поле вводу, фізика вікон |
| `src/ui.js` | меню, форми, жести, синхронізація зі станом логіки |
| `logic/` | модулі Voice Finance, тести, документація (`START_HERE_CLAUDE.md`) |
| `docs/` | те, що публікується: `index.html`, manifest, іконки |

## Що не реалізовано

Тікер і деталі ринку, скан чека, підключення банків, голосовий ввід, імпорт JSON. Логіка для частини з них є у `logic/`, інтерфейсу немає.

## Перевірено

Тести логіки та headless Chromium з підробленим `html2canvas`. На справжньому iPhone Safari (швидкість, клавіатура, свайп від краю, html2canvas) інтерфейс ще треба перевіряти вручну.
