# Інструкції для Claude у цьому репозиторії

Проєкт: Voice Finance з інтерфейсом Liquid Glass. Відповідай українською, коротко, без вступів.

## Обов'язково прочитати
`logic/START_HERE_CLAUDE.md` і `logic/CLAUDE_LOGIC_FULL.md`. Вони описують логіку та обмеження, інтерфейс тут свій.

## Правила
- Дані змінюються лише через сеттери `finance-core`/`application`. Демо-даних не підставляти замість реальних. Платних API не додавати.
- Оригінальний репозиторій `dimasdont-lab/voice-finance-free` не змінювати. Відомі баги джерела не виправляти тихо, а пропонувати окремо.
- Ключ сховища `voice-finance-glass-v1`. Оригінальний `voice-finance-v01` не чіпати.
- Звітувати чесно: що перевірено в headless Chromium, а що на iPhone не перевірялось. Банки, скан і ринок не називати готовими.

## Вимоги до інтерфейсу
- Скло це справжня WebGL-рефракція, а не CSS `backdrop-filter`. Інтерфейс живий DOM, 60 fps, білий текст читається.
- Знімки DOM у текстури: html2canvas по блоках сторінки в прихованому iframe. CSS блоків не повинен залежати від предків. У iframe копіюються **всі** `<style>`.
- Крапля-поле вводу над клавіатурою, кнопка відправлення на touchend (iOS гасить click після `preventDefault` на touchstart).
- Панель «Додатково» і випадайки: скло, затемнення 50%, малий blur. Під верхнім вікном шари зменшуються на 20% і зсуваються, по краю екрана легке розмиття й тінь. Радіус великих вікон 62 pt (iPhone 17 Pro).
- Жести: свайп вниз закриває випадайку, налаштування й «Додатково». Свайп від лівого краю це назад.

## Збірка й перевірка
`npm run build` → `docs/index.html` (комітити). `npm test`. `node tools/smoke.cjs`. Після змін перевіряй у браузері, не лише тестами.
